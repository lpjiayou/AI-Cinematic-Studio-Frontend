# Story World asset provenance

- Creation date: 2026-08-10
- Source method: OpenAI built-in image generation, followed by local 16:9 resizing and WebP conversion.
- Rights status: generated specifically for the AI Cinematic Studio frontend prototype; internal project use.
- World canon: original “未来之城” production-design concept; no commercial film, game, organization, logo, or scraped artwork was used.
- Theme pairing: the same four assets are used in Light and Dark themes; only ACS surfaces and overlays change.
- Runtime crop: Overview uses `55% 52%`; Timeline and Faction Board use `50% 50%`; Map uses `52% 50%`.
- Accessibility: exact alternative text is rendered in HTML by the Story World page and is not baked into the images.
