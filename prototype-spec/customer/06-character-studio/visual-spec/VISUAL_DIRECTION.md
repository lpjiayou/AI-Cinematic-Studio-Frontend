# Character Studio — Visual Direction

Version: `V4.1`

## Purpose

Define the visual language of a professional cinematic character-development room.

## Product Feeling

The user should feel:
`这个角色正在成为一个可以持续存在于故事中的人物。`

Not:
- avatar generator;
- game customization UI;
- database record;
- AI prompt page.

## Visual Priority

1. Character Overview
2. Identity
3. Appearance
4. Personality + Character State
5. Relationship
6. Visual Consistency
7. AI Suggestions

## Visual Language

Use:
- cinematic character imagery;
- production-design references;
- calm archival cards;
- clear world-context cues;
- restrained status badges.

Avoid:
- body sliders;
- numerical face parameters;
- RPG statistics;
- neon gaming UI;
- dense admin forms;
- chat bubbles;
- model settings.

## Identity Invariance

The same character identity is preserved:
- across themes;
- across asset thumbnails;
- across overview/face/costume imagery;
- across local previews.

Visual variety may change framing/costume detail, not core identity.

## Acceptance

PASS when:
- the character is clearly the product focus;
- narrative and visual identity feel connected;
- no false Identity Lock state exists;
- page feels cinematic and professional;
- relationship/personality information supports future Script work.
