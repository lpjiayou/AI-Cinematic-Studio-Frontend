## Cutover-critical conclusion

All four K2 method-aware resources are missing from the Frontend adapter and browser client: `execution-method-plan`, `method-aware-input-plan`, `method-aware-video-route`, and `explicit-audio-requirement-route`. The current Production page is therefore a legacy-history compatibility/control-plane view, not the primary successor workflow. Its read compatibility should remain, while new-write affordances move to a server-derived method-aware flow.

The browser boundary stays closed-world: Browser → Frontend Experience Adapter → Creator Public HTTP/API → Core. The client may neither mint authority references nor select `executionMethod`.
