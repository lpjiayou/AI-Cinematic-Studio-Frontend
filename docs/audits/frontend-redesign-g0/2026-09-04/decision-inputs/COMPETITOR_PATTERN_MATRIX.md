## Patterns to adopt

1. **Convergent objects, not duplicate modes.** Quick Create and Project Production should create or reference the same job, candidate and asset objects.
2. **Contextual depth.** Start with a brief/prompt and references; reveal compatible parameters and blockers for the selected task or shot.
3. **Asset permanence.** Uploads, generated candidates, admitted assets and timeline clips need distinct lifecycle labels inside one searchable library.
4. **Selection-scoped inspector.** Inspector content follows the selected shot, candidate, clip or effect; authority and evidence remain separately inspectable.
5. **Progressive device strategy.** Mobile handles quick creation, monitoring and review. Dense timeline editing is not compressed into a phone-only replica.

## Patterns explicitly rejected

- A model picker that lets the browser override Core’s execution method.
- One-click output presented as a master, publication-ready asset or approved canonical result.
- Hidden Provider fallback, credit-driven routing, or silent local-fixture substitution.
- Marketing claims used as proof of product behavior.
- Competitor visual language, assets or terminology copied into ACS.
